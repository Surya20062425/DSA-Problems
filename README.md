# DSA-Problems

A collection of LeetCode and interview-style algorithm problems solved in Python 3.

## Structure

All solutions are in the root directory as standalone `.py` files. Each file contains a `Solution` class with the problem's method.

## Topics Covered

- Arrays & Strings
- Linked Lists
- Trees & BST
- Graphs & BFS/DFS
- Dynamic Programming
- Sliding Window
- Greedy Algorithms
- Binary Search

## Running

Each file can be run directly:

```bash
python filename.py
```
